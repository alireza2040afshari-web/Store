## 📌 About The Project

Django Store is an e-commerce web application designed to provide
a structured platform for displaying products and managing product
information.

The project focuses on building a maintainable web application
using Django's MVT architecture and reusable HTML templates.

## ✨ Features

- 📦 Product listing and product details
- 💰 Product prices and discounts
- 🖼️ Product image display
- 🎨 Custom website styling
- 🌓 Theme switching
- 📱 Responsive user interface
- 👤 User profile functionality (in development)
